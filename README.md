# MercadoLibre

## chatbot — Mostrador

Panel de Mostrador, el bot que responde con IA las preguntas de los compradores de MercadoLibre.
Es una app instalable (PWA): se abre desde el navegador y se puede instalar en el celular y en la PC.

- Dirección: https://oleandro78-svg.github.io/MercadoLibre/chatbot/
- El servidor (Supabase) guarda los datos y pide usuario y clave; acá solo está la pantalla.
